## 真实桌面验收顺序

1. `scripts/start.ps1` 启动桌面端；分别分析仓库图片与测试视频，再更换实际训练素材。
2. 保存一条视频结果，确认 SQLite 只插入一次；关闭托盘中的程序并重启，从历史恢复图像、帧、建议和对比快照。
3. 把原视频移动到其他位置，确认已保存抽样帧仍可查看；恢复原位置。
4. 编辑训练信息并重启，按日期/标签筛选；检查超过 20 条时的分页。
5. 导出 HTML/JSON，测试取消、不可写位置、离线打开和中文路径。
6. AI 未配置时验证本地流程；有可用密钥时再验证真实 AI 请求，不把模拟接口测试当作 API 成功。
