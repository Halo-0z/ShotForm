# ShotForm 三方向可视预览 · 第 01 轮

用户于 2026-11-15 要求先制作 A/B/C 可视预览并放在一起比较。本轮只交三个代表性的分析工作台首屏，等待选择后再实现完整界面。

- 打开 `style-explorer.html` 可离线比较；本机在线入口为 `http://127.0.0.1:1423/style-explorer.html`。
- 每张候选画布为 1440×900，可在对比页并排或单张按实际尺寸查看。当前应用的审计截图作为“现状”参照。
- A 球场回放台：主画面与播放工具相邻，右侧集中判断依据。推荐用于频繁逐帧检查。
- B 教练复盘册：结论先行，横向证据图带与连续阅读排版，适合训练记录和复盘。
- C 动作序列台：五帧序列做主导航，当前帧居中，角度和判断在两侧就地读取。
- 三版均使用既有 HarmonyOS Sans SC 字体，统一字体子集保存在 assets/shotform-ui.ttf。品牌色沿用项目规范；A/C 展示深色，B 展示浅色，最终选中方案会做浅深双主题，当前色调不是方向边界。

## 内容与素材

共用内容只维护在 `content.json`，通过 `build_preview.py` 填入三个独立的 HTML/CSS 模板。框架和页面骨架独立制作，没有以同一模板换颜色。各方向的次级说明可按阅读方式缩写，但关键结论、角度、置信度、时长、备注一致。

五张真实视频帧来自项目已有 `tests/fixtures/upload-sample.mp4`，提取时间为 0.25、0.75、1.25、1.75、2.25 秒，素材总长约 2.97 秒。为减少原手机播放器边缘干扰，仅截取原始 592×1280 视频的矩形 `(x=0, y=160, width=592, height=900)`。未生成或伪造动作图像，未运行识别模型，未把这些帧当人工标注真值。

**所有分析文字、角度与 71% 置信度均为共用的布局夹具，不代表这段视频的实测结果。** 图像保留素材本身的画质限制；不要用此稿评价算法或动作正确性。对比页外壳已明确披露这一点。

这些是静态首屏视觉稿。保存、导出、播放、帧选择和导航仅展示外观，未接业务；未做响应式、动效、完整主页或次级状态。没有调用付费 AI，没有修改产品源码、路由、算法、数据库或历史协议。
