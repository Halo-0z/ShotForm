# 篮球游戏 SVG 界面

用户选择「篮球游戏：更醒目的立体感与动效」。在已选定的 A 球场回放台上深化，保留真实球员封面、蓝铜配色、清晰的数据层级和浅深主题。主要任务仍是上传、回放、对比与训练记录。

## 预览与实现

- 本地预览：http://127.0.0.1:1420/docs/ui-audit/2026-11-15/basketball-svg/preview.html 。18 张实际界面截图，浅深主题并排；入口可打开可操作应用。
- `src/components/basketball/`：原创篮球、球场、球衣、回放、保存、导出等 SVG，以及按钮刻线、篮筐插画、透视球场底座。无新增外部素材或付费服务；真实球员图沿用原资产。
- `src/assets/basketball-game.css` 与共享 Button：立体底边、高光、按压反馈、键盘焦点、禁用及加载状态；导航、上传、回放、历史、对比、模板、设置与托盘统一视觉。
- 保持原生按钮语义与业务处理；装饰 SVG 隐藏于辅助技术，不替代按钮名称。

## 动效

1. 按钮悬停上浮 2px，按下下沉 2px；不推动相邻布局，辅助判断当前交互。
2. 篮球图标轻转、上传插画轻抬，提示操作入口与拖入状态。
3. 导航选中厚边、关键帧铜色标识与主题选项压入效果，区分当前状态；延续首页到工作台的雾化转场。

`prefers-reduced-motion` 禁用新增移动反馈。正常速度操作录屏在 `motion/workflow.webm`，包含入口、主题、导入、键盘裁剪和播放暂停；浏览器运行错误为 0。未进行正常速度手感的主观播放验收，不将自动探测等同于手感通过。

## 验证

- `vue-tsc --noEmit` 通过；修改文件 ESLint 无错误，Button 保留 3 条可选 prop 默认值警告。
- 8 个既有浏览器回归文件共 25 个案例，各跑 3 次，75/75 通过。覆盖保存失败后重试及刷新读回、报告导出、历史、模板、对比、裁剪与主题。
- 新增控件测试最初把入场结束误写成 `transform: none`；浏览器实际为单位矩阵。改为检查位移归零，再检查悬停、按下、邻居位置和键盘操作。最终控件与上传两组回归共 9 个案例，各跑 3 次，27/27 通过。
- 8 个相关 Node 测试文件共 36 个检查通过。修正其中一处既有过期文案断言「适合分析」为现有「片段时长合适」，没有改变业务代码。
- `after/` 留存 45 个实际页面状态，含 1440×900、960×640、200% 放大与 720×450 reflow。观测无横向溢出；预览页 18 张图均加载且无横向溢出。
