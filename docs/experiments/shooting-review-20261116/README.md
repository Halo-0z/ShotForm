# 三段真实素材：预测与人工复核交接（2026-11-16）

本轮在用户提供的三段投篮视频上运行 **Heavy CPU 和 RTMPose-m CUDA**，各单遍75帧，保存逐帧所有人物预测、原始分数、角度/原因、阶段耗时与进程记录，以及75张骨架对照图。没有执行RTMPose CPU、额外重复速度实验或RTMW。默认Heavy、产品角度规则和历史格式未修改。

**人工确认帧仍为0。没有计算人工配对角度误差、人工覆盖率、漏检率或残差抖动，也不判断哪个模型更准确。** 图上分数颜色与JSON中的阈值接受数仅表示当前模型输出状态，两个模型的分数含义不同，不能作为跨模型精度依据。

## 输入与取帧

均为720×1280、30fps原图，逐帧解码，无裁剪、缩放、插值、预测预填或自动标注。取帧窗口在推理前固定：

| 原视频前缀 | 样本ID        | 源帧号（零起始、含两端） | 时间           | 帧数 | 用途                                              |
| ---------- | ------------- | ------------------------ | -------------- | ---: | ------------------------------------------------- |
| c99ae…     | outdoor-shot2 | 192～216                 | 6.400～7.200秒 |   25 | 优先试标；包含已核验的192、198、204、210、216五帧 |
| c78ed…     | indoor-upper  | 30～48                   | 1.000～1.600秒 |   19 | 补充上肢；独立试标页取30、34、38、42、46帧        |
| 139c…      | dark-edge     | 120～150                 | 4.000～5.000秒 |   31 | 暗光、低机位、出画、远处行人等困难情况            |

原视频SHA-256及每张原PNG哈希保存在 `dataset.json`，本轮再核对了三段源文件及①原有五帧。原始PNG和两模型使用相同的数据文件；对照JPG是展示副本，不用作人工点选或模型输入。宽松衣物下的髋膝、远侧手臂、图外部位仍待人工判断，绝不把预测位置写入人工字段。

## 本次检测记录（不是准确率）

| 片段  | Heavy输出情况                    | RTMPose输出情况        |
| ----- | -------------------------------- | ---------------------- |
| ①25帧 | 25帧返回单套骨架                 | 25帧返回单套骨架       |
| ②19帧 | 16帧单套、3帧多套导致归属歧义    | 19帧单套               |
| ③31帧 | 24帧单套、6帧多套歧义、1帧无检测 | 12帧单套、19帧多套歧义 |

“单套”只意味着按既有选择规则选中一个模型输出，**没有人工确认身份或点位正确**。“多套”也不意味着画面真的有多个目标；例如②源帧48的Heavy对照图可见两套高度重叠的骨架，保留为疑似重复检测供人工复核。③源帧120中候选同时输出前景人物和远处行人的骨架，未有目标框时记录歧义。不能把19次歧义叫作19次漏检，或把能返回骨架叫作识别正确。

所有输出人物均保存在每帧 `people` 中。`selected_person_index` 只指本帧列表内的索引，不是跨帧身份跟踪ID；`points` 保留选中人的旧实验接口，没有选中时为空并有原因。Heavy保留33点及原生相对z，RTMPose保留COCO17映射点，候选z仍为null；二维点为原图像素，分数不抬高下限。

对照图仅画双方共同的左右肩肘腕髋膝踝12点和身体连线：绿实心/实线=已选择且分数≥0.55；蓝色=尚未归属的人物；橙色空心/虚线=低分输出。图外点仍留在JSON，图中不夹到边界、不补零。**绿点并不代表人工确认的可见或正确点。** 逐帧 `review.json` 记录人数、归属原因、全部人物点状态、选中角度的缺失/低分原因和阶段耗时。

所有图片及个人素材只保留在忽略目录 `experiments/local/`，不随Git推送。

- 优先①原有5帧无预测试标页：`experiments/local/video-review-20261116/five-frame-trial/5帧试标.html`。
- ②上肢5帧无预测试标页：`experiments/local/shooting-review-20261116/dataset/②上肢5帧试标.html`。
- 模型复核入口：`experiments/local/shooting-review-20261116/逐帧对照/index.html`。每帧有原图/Heavy/RTMPose并排图、原尺寸图片链接及可展开的状态/计时明细。
- 全部本机原始结果：`experiments/local/shooting-review-20261116/run/`，包含两组完整预测和stdout/stderr。最终图像目录为 `逐帧对照/frames/`；早期 `review/` 是同次预测的初版渲染，最终文案与哈希以 `逐帧对照/` 为准。

请**先在无模型叠加页独立点选，再查看模型对照图**，避免预测位置影响人工真值。①先做5帧；②补可辨认的肩肘腕，髋膝或远侧手臂看不准就设未知，不强凑12个坐标。页面逐帧确认要求每个点有“已标或未知”的决定，并不要求12点都可见。③先保留困难案例，后续由人工确认前景目标框、是否出画及点位状态。未知点无坐标，相关角度不纳入误差。

每个页面导出JSON后分别保留文件名，提供本机路径；与对应原数据合并校验后冻结标注版本。再计算左右肩、肘、髋、膝各自的人工可定义角度分母、模型有效数、共同有效配对MAE/P95和覆盖率。没有足够相邻人工标签前不计算残差抖动。下阶段不是继续增加推理次数。
