# 篮球游戏 · 球馆质感版

用户要求上一版更精美、更全面，并授权使用生图素材。沿用已确认的 A 回放台与篮球游戏方向，升级为有真实球场氛围和器材材质的桌面训练工作台。首要操作仍是上传素材，分析视频和数据仍为工作页面主角。

## 预览与资产

预览：http://127.0.0.1:1420/docs/ui-audit/2026-11-15/arena-premium/preview.html 。18 张实际页面图按浅深主题并排，提供可操作应用与上一版的入口。所有图已加载，无横向溢出。

两张新增素材由内置 imagegen 生成，型号未由工具暴露，未宣称使用 image2.5。提示词、原图、运行路径和压缩信息见 [ASSETS.md](ASSETS.md)。运行 WebP 合计 177,662 bytes，透明器材保留 alpha；原图保存在 assets-source/。背景与器材只作装饰，不代表真实场馆或分析证据。既有真实球员剪影沿用原素材。

## 完整界面的变化

- 首页：球馆灯光、木地板、真实球员主体与清晰文案组成主视觉；新增回放、档案和对比的真实导航入口。
- 上传：透明三维器材与操作左右并排；低窗口、窄容器、200% 放大时隐藏装饰图，保留说明和选择按钮。
- 共享控件：保留立体按压感，去掉密集 SVG 内框，统一金属边缘、高光与按键厚度；暗色导航在两主题中一致，图标有统一底座。
- 分析：视频边框、播放控制、关键帧与数据侧栏统一；历史筛选、模板、对比与设置面板采用相同材质和边缘。
- 历史图表：增加纵轴名称上方空间，修复浅深两主题“角度 (°)”被裁切的问题；没有更改趋势数据计算。

代码集中于 `src/assets/arena-premium.css`、`CourtArtwork.vue`、Home、上传页面及 ProgressChart。原业务处理、后端与模型保持不变。

## 动效与减法

保留按钮悬停上浮 2px、按下下沉 2px；器材悬停轻抬，拖入状态用描边和小幅位移回应；首页到上传延续雾化转场，导航和快捷入口保留状态反馈。减少动态效果时停用装饰位移。没有背景自动缩放或覆盖数据的循环动画。

去掉按钮内重复刻线、首页旧 SVG 地板与关键帧重复外描边。既有操作说明和数据来源说明没有为了简洁而删除；新增快捷入口的说明仅解释目标任务。

## 视觉评审与取证

完成 1 轮独立「存量已有界面润色评审」，不打分，评审者只看任务、DESIGN.md、新旧截图，未读实现代码。评审认为新场馆、真实球员、三维篮架及导航材质比旧版统一，工作台仍以证据为主；发现的唯一 P2 是趋势图轴名称裁切，已修复并由主 Agent 复看浅深截图。

主 Agent 另修复初稿上传插画尺寸覆盖、深色按钮浅色底边、200% 放大上传列过窄的问题。最终 `after/` 的 45 个状态包含双主题、常用与错误状态、960×640、200% zoom 与 720×450 reflow，观测无横向溢出。

`evidence/report.json` 的页面及 2× 检查无视觉 lint 告警；2 项失败仅为本机缺 ffmpeg 无法导出 MP4，保留了入场/设置切换的三帧。另用 Playwright 编码录制 `motion/workflow.webm`，包含入口、设置主题、导入、键盘裁剪和播放暂停，浏览器错误为 0。没有主观播放正常速度录屏，因此不声明正常速度手感已验收。
