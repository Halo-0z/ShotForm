## 同品类参考及取舍

已浏览官方画面并保存 `references/kinovea-ui.png`、`references/hudl-basketball.png`，仅供结构比较，不作为产品素材。

来源：[Kinovea 播放界面](https://kinovea.readthedocs.io/en/latest/observation/playback_ui.html)、[Hudl Sportscode](https://www.hudl.com/products/sportscode)。官方文档画面不等于已测试其当前桌面版本。

可观察的结构关系与本产品取舍：

1. Kinovea 中图像占绝大部分视口，信息栏压成一行：采用证据优先的面积分配，ShotForm 同时保留简短判断。
2. 播放、逐帧按钮紧邻时间轴：采用动作与对象靠近的关系，不把时间控制散到报告角落。
3. 片段范围与播放位置分别成轨：保留裁剪区间和当前帧的区别，不把它们混成一个进度。
4. 导出集中在控制区边缘：采用明确次级操作组，不让每种格式都争抢主 CTA。
5. Hudl 篮球画面、事件与时间轨道可并看：采用空间对应关系；单人投篮不复制球队事件编码面板。
6. 模板/事件选择有明确选中态：采用可见选择和明确对象名称，不用光晕替代状态。
7. 两者都让业务对象承担主视觉：内页不以明星背景覆盖训练证据；明星素材留给首页。
8. 不沿用参考的旧式密集图标、球队多色编码和超多轨道；保持 ShotForm 既有字体、色板与单次训练尺度。

## 三个待选择的方向

三个方向都保留“电影封面 + 训练工作台”，不改变品牌色和路由。按 oil-ui 的既有品牌例外，差异集中在骨架、主视觉和阅读顺序，而不是换三套皮肤。

### A · 球场回放台（推荐）

- 北极星：先看清这次出手，再追问判断依据。来自教练暂停回放、逐帧检查的工作场景。
- 首页骨架：满版球员投篮主视觉，短标题与开始入口放在图像安全区；删去三张介绍卡，让封面成为一次明确开场。
- 工作台骨架：紧凑标题/结论条 → 大幅视频或姿态证据与相邻时间轴 → 右侧可收拢的依据/建议；历史采用可扫读列表，比较先展示差异和对象。
- 字体：沿用 Instrument Serif/ZCOOL XiaoWei 作为封面候选；内页 HarmonyOS Sans SC，标题 28–32、正文 14–16、数值 Cascadia Code。实际字体是否加载需实现时核查。
- 色彩：Arena Black `#0A0D12` / Workbench Ink `#141922`、Warm Bone `#F3EEE6`、Paper Mist `#FAF7F2` 构成主题；Steel Blue `#5D7396` 操作；Shot Copper `#C9823D` 标出关键帧和证据，来自既有品牌。
- 控件：Lucide、适中圆角、统一触达面积；封面保留雾化衔接，工作台用短选择/展开反馈。具体动效方案在方向选定后补齐。
- 放弃：通栏产品介绍、每项指标一个浮卡、每页一张明星海报。
- 适配理由：现有视频、逐帧、姿态、角度能力最直接受益；改动可集中于前端构图与共享组件，业务边界清楚。

### B · 教练复盘册

- 北极星：让训练结论和下一步成为一份可阅读的复盘记录。来自教练训练笔记的内容顺序。
- 首页骨架：通栏大字标题，下面一条宽幅投篮图带与开始入口；不做默认左右分栏。
- 工作台骨架：顶部直接呈现当前结论 → 通栏证据区 → 下方按依据/建议排成连续阅读页；训练备注、日期和前后变化融入记录结构。高级详情按需展开。
- 沿用相同品牌字族与浅深主题；展示字仅出现在封面，内页靠标题/正文/数字比例建立秩序。纸面浅主题和墨色深主题都有完整实现，不以明暗作为方向差异。
- 主视觉由真实动作与连续排版构成，减少容器边框；图标保持 Lucide，控件与 A 共用规范。
- 取舍：对训练档案、中文建议、报告阅读更友好，但逐帧高频操作不如 A 集中。

### C · 动作序列台

- 北极星：让一次出手的时间顺序成为界面本身。来自准备、上举、出手、随球的动作序列。
- 首页骨架：居中单一腾空球员，标题与开始入口收在底部固定操作区；画面保持一个主角。
- 工作台骨架：横向关键帧带成为主导航，选中帧在中央放大，结论与相关角度就地展开；比较用相同阶段对齐，而非先看百分比分数环。
- 沿用品牌字体、蓝色交互和铜色证据；以画面、阶段标记和时间刻度识别产品，不添加装饰性科学图形。
- 取舍：视频动作过程最鲜明、与通用后台差异最大；图片模式必须有同样清楚的单帧布局，窄窗及现有阶段数据不足时要合理降级，实施复杂度最高。

差异检验：A 是满版封面/证据工作台，B 是通栏标题/连续复盘，C 是居中物件/时间序列。三者不是相同线框换颜色；品牌字族和色板因既有规范共用。没有直接复制参考的图标、色彩编码和球队业务。文字方向交付后，已按用户要求渲染三个代表性的分析工作台首屏，并放入同一对比页；主页封面尚未制作。
