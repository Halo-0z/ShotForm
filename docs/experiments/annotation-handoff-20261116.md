## 请用户完成的操作

1. 先做①的5帧，再做②的5帧；独立看原图点选，完成前不参考模型对照图。填写标注者姓名或稳定代号。
2. 逐帧确认目标是否在画面内。目标可见时选择“存在”，拖框包含该投篮者可见身体，尽量排除其他人；框用于目标归属，不改变模型输入。如果人物重叠导致模型仍有多个匹配，要保留歧义，不按误差较小来选预测。
3. **左右是人物自己的左右**，不是屏幕左右。侧身、转身时沿肩—肘—腕及髋—膝—踝追认同一肢体；不能为了让骨架顺眼交换左右。无法判断左右或关节中心时设未知。
4. 点选关节中心，而不是衣物轮廓或球的位置。`visible` 表示中心直接可辨认；`occluded` 只用于虽遮挡但仍有可靠视觉依据的位置；宽松衣物、严重遮挡、模糊、出画、左右不明时用 `unknown`，不猜坐标。未知点不能带 x/y。
5. ②优先肩肘腕；髋膝或远侧点无法定位就设未知。全部12个点要有“已标或未知”的状态决定，**不要求12个坐标**。选择该帧遮挡分组，在备注说明不确定的部位，再勾选逐帧检查；修改框/点/信息会撤销该帧确认。
6. 每页导出JSON。页面关闭前先导出；下次使用“导入继续”。把两个实际JSON文件的本机路径交回，再做格式验证和人工复核。

浏览器点击回归中的 `SYNTHETIC BROWSER TEST` 仅存在于自动化测试会话/临时下载，不写入用户页面或原始dataset，不能当作人工标签。

## 什么角度可以定义

角度使用原图像素中的三点二维夹角，顶点在中间；左右分开，不混用两侧点。

| 关节 | 同侧三点 | 缺少任一点时                           |
| ---- | -------- | -------------------------------------- |
| 肩   | 髋—肩—肘 | 不可定义，因此只标肩肘腕不保证能算肩角 |
| 肘   | 肩—肘—腕 | 不可定义                               |
| 髋   | 肩—髋—膝 | 不可定义                               |
| 膝   | 髋—膝—踝 | 不可定义                               |

未知、未确认、缺失、非有限或退化三点不进入人工可定义数。即使最后只能可靠定义几帧肘角，也如实保留；不补点来凑样本量。

## 已接通的逐关节输出口径

`evaluate.py` 的 `pairwise[].by_joint` 包含左肩、右肩、左肘、右肘、左髋、右髋、左膝、右膝八项。置信度沿用实验既有三点各自≥0.55规则，不调整产品Rust角度规则。

| 字段                                 | 定义                                                                |
| ------------------------------------ | ------------------------------------------------------------------- |
| `human_definable_n`                  | 此关节人工可定义样本总数 N                                          |
| `model_valid_n` / `model_failed_n`   | 各模型在 N 中的有效数及失败数，失败保留在分母                       |
| `model_failure_reasons`              | 缺点、低置信度、退化等拒绝原因                                      |
| `model_coverage`                     | 每模型有效数 / N                                                    |
| `common_valid_n` / `common_coverage` | 双方共同有效数及其 / N                                              |
| `each_model_mae_p95_degrees`         | 各模型自身有效集合的误差汇总，含 n、mean（MAE）、median、p95        |
| `paired_mae_p95_degrees`             | 只在共同集合上计算的每模型误差，用于配对比较，同时展示前述失败/覆盖 |

P95使用排序后的第 `ceil(0.95*n)` 项。少量标签的P95接近最大值，不能作为总体性能证明。空集合误差、空分母覆盖率为null，不补零。

无检测与目标归属歧义分别报告；`target_unavailable_*` 不能叫作漏检率，`miss_rate` 保留null。例如暗光片段RTMPose同时返回投篮者和行人，要先通过目标框确定归属，不能把19帧多套输出写成19次漏检。

两组5帧分别间隔6帧、4帧，是稀疏试标，**不报告残差抖动**。工具默认关闭时间指标；只有另行人工确认连续标签并设置 `temporal_labels_confirmed=true`、相邻源帧号差1且两端角度有效时才计算。未知中间帧断开相邻对。本批不设置该开关。
